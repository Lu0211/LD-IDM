# LD-IDM: An Intelligent Driver Model Considering Lateral Deviation

## 1. Environment
- Python 3.10 is required.
- pytorch, Numpy, matplotlib, pandas are required.

## 2. Language
- python

## 3. Data
- The datasets used can be downloaded from the uploaded datasets.zip file.

## 4. Model
- To implement the IDM model and Dynamic IDM model, simply run the IDM_or_Dynamic_IDM.py file. To implement the LD-IDM model, run the morning_LD-IDM.py file.
- To implement the Dynamic LD-IDM model, run the morning_Dynamic_LD-IDM.py file.
- The road network file and vehicle routing file are located in the .net.xml and .rou.xml files, respectively.

## 5. Results
- All experimental results are located in the HighD_results and NGSIM_results directories.

## 6. Remark
- The implementation of different car-following combinations and time periods are similar; only the road network file and vehicle routing file need to be modified.
